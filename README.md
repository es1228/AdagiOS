# AdagiOS
A simple WebOS to display demos of my other projects.

# Features
- Login Screen (Passwordless)
- Top Bar (clock, logout, and active app label)
- Dock (with apps listed below)
- Quick Notes App: save any quick notes you have, the latest note is saved via localstorage
- Weather App: A weather app I made named OpenSky, see the features at https://github.com/es1228/OpenSky
- Satellite Tracker: A satellite tracker I made named SatTrack, see the features at https://github.com/es1228/SatTrack
- Chess App: A chess review site I made named Tempo, see the features at https://github.com/es1228/Tempo
